# Multi-Protocol Governance Audit Framework

A framework for auditing the on-chain governance of live DeFi protocols
against a fixed control catalogue, scored by a runnable engine from
parameters verified against primary sources.

## Audited protocols (this release)

| Protocol | System | Score / 100 |
|----------|--------|-------------|
| Aave | Governance V3 (Core + Executors) | 92.50 |
| Compound | Governor Bravo + Timelock | 86.13 |
| Uniswap | Governor Bravo + Timelock | 75.88 |

17 findings: 1 High, 8 Medium, 8 Low. The single High finding is Compound

could not recall.

## Layout

- `framework/spec.md` — framework specification, control catalogue, threat model
- `framework/scoring-rubric.md` — rubric detail (pass / partial / fail criteria)
- `framework/rubric.json` — machine-readable rubric (the engine's source of truth)
- `audit-engine/audit.py` — Python 3 stdlib-only audit engine (offline)
- `protocols/*.json` — one verified profile per protocol (parameters + citations)
- `protocols/*.md` — one rendered audit report per protocol (generated, committed)
- `claims.md` — claim-to-evidence index (every claim maps to a file + output line)
- `findings.md` — all severity-ranked findings (generated from engine output)
- `citations.md` — every primary source used, with URL and what it establishes
- `evidence.json` — machine-readable summary (protocols, scores, findings counts)
- `docs/index.html` — rendered findings page for GitHub Pages (generated)
- `scripts/run_all.sh` — run the engine, verify digests, check generated files
- `scripts/clean_reproduce.sh` — re-run from a fresh copy, require byte-identical outputs
- `scripts/verify_digests.sh` — verify SHA256SUMS
- `outputs/run1/` — unedited run logs, score JSONs, and audit reports
- `outputs/run2-clean/` — clean-reproduction outputs (byte-identical to run1)

## How to run

```bash
bash scripts/run_all.sh            # engine -> outputs/run1, checks, digests
bash scripts/clean_reproduce.sh    # fresh-copy re-run; must report MATCH
bash scripts/verify_digests.sh     # sha256sum -c SHA256SUMS
```

Requirements: Python 3 (standard library only), bash, sha256sum, diff.
No network access and no pip installs are needed to run the engine.

## Reproduce

`scripts/run_all.sh` runs `audit-engine/audit.py` on all three profiles,
checks the generated reports against the committed `protocols/*.md` reports,
regenerates `findings.md` and `docs/index.html` and diffs them against the
committed files, runs the consistency checks, and verifies digests.
`scripts/clean_reproduce.sh` copies the pack (excluding `outputs/` and
`.git`) to a fresh directory, runs the full pipeline there into
`outputs/run2-clean`, and diffs it against `outputs/run1`; it must report
MATCH (byte-identical).

## Generated files and digests

- `docs/index.html` is generated from engine output by
  `scripts/build_docs.py`, so it is excluded from `SHA256SUMS` (this is
  stated in `framework/spec.md` section 7 as well).
- `outputs/` is generated by the scripts and is not covered by `SHA256SUMS`.
- `SHA256SUMS` covers every other pack file.
- `submission-text-final.txt` is a submission draft, not part of the pack,
  and is not covered by `SHA256SUMS`.

## Honest limitations

- Compound's Governor Bravo mainnet address was not verified from a primary
  source at audit time (docs use a `0x123...` placeholder); scored partial.
- Uniswap's Timelock grace period (14 days) is inferred from the shared
  Compound Timelock codebase, not separately verified for Uniswap.
- Uniswap's guardian holder is not verified from a primary source.
- Aave Governance V3 Level 2 quorum / differential exact values and the
  on-chain proposal-creation threshold are not stated in the current docs.
- The engine scores documented parameters and observed proposals; it does
  not re-execute proposals on-chain.
